# 通用项目学习总框架（总）

## 目标

将任意项目学习统一为可执行的系统化路径，先总后分，确保章节连续、节奏可控。

## 全局流程

1. 明确项目学习目标
2. 产出章节总览
3. 逐章执行（每章先总后分）
4. 章节复盘与状态更新
5. 周期性里程碑评估

## 章节依赖约束

- 必须先确认上一章状态，再进入下一章。
- 章节推进遵循线性顺序，避免跨章跳读。
- 若用户要求调整顺序，先重排总览再继续。
