# LaTeX 公式渲染规范

## 目标

统一课程文档中的数学公式表达，确保公式可直接按 LaTeX 渲染。

## 强制写法

- 行内公式：`$...$`（标准输出）
- 块级公式：`$$...$$`

## 兼容输入与改写

- 兼容输入：`\(...\)` 可作为临时输入格式
- 落盘前必须统一改写为：`$...$`
- 禁止在最终文档中混用两种行内分隔符

## 禁止写法

- 使用自然语言伪装公式（例如“x平方加y平方”）替代可渲染公式。
- 使用截图或图片替代可编辑公式。
- 在同一文档中混用不兼容的公式分隔符。

## 文档落地要求

- 任何含数学表达的章节，必须将公式原文写入 `chapter-XX.md`。
- 若本章无公式，标注“本章无公式内容”。
- 公式周围保留必要上下文，避免只存孤立公式。

## 自检清单

- 是否所有公式都使用 LaTeX 分隔符？
- 是否存在无法渲染的占位表达？
- 是否遗漏了章节中的关键公式？
- 是否与章节门禁、进度日志记录一致？
- 是否仍残留 `\(...\)` 未改写项？
