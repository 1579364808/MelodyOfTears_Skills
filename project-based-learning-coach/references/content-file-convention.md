# 课程内容文档落地规范

## 目标

确保课程内容可追踪、可复用，所有产出必须同步写入 Markdown 文档。

## 必需文档

- `course-outline.md`：课程总览、章节依赖、里程碑、评估方式。
- `chapter-01.md` ... `chapter-N.md`：每章独立文档，按“总-分”结构维护。
- `progress-log.md`：章节状态与每次推进记录。

## 章节文档结构

每个 `chapter-XX.md` 必须包含：

1. 章节总览（总）
2. 分节计划（分）
3. 公式渲染区块（如涉及公式）
4. 本章产出物
5. 本章检查点
6. 许可状态（是否获准展开正文）

## 更新规则

- 每次输出章节内容时，必须更新对应 `chapter-XX.md`。
- 未获许可阶段，只允许更新“章节总览/分节计划/许可状态”。
- 获得许可后，才能向该章写入正文讲解。
- 若出现数学表达，必须使用 LaTeX 公式写法并写入文档。
- 若无数学表达，必须在公式区块显式标注“本章无公式内容”。

## 路径建议

默认目录：`./learning/`

- `./learning/course-outline.md`
- `./learning/chapter-01.md`
- `./learning/progress-log.md`

若用户指定其他目录，优先使用用户路径。
