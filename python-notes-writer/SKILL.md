# Python 知识点增量记录 Skill

## 何时触发

用户表达意图：将当前对话中讨论的 Python 知识点**持久化保存到本地笔记**时触发。

典型触发词：
- "更新文档" / "更新python文档"
- "记到笔记里" / "记录这个"
- "写入知识点" / "写到文件里"
- "添加到笔记" / "保存下来"
- "写一个笔记" / "整理成文档"

## 工作区

笔记目标目录：`<workspace>/Python其他知识点/`

## 增量写入规则

### 1. 检查已有文件

读取 `Python其他知识点/` 目录，列出所有 `*.md` 文件。

### 2. 判断是新建还是追加

- 如果本次知识点的**主题与某个已有文件匹配**（标题或内容关键词重叠）→ **追加**到该文件末尾，用 `---` 分隔新内容，开头标注日期
- 如果**不匹配任何已有文件** → **新建**文件，编号接续当前最大序号

### 3. 编号规则

文件名格式：`{序号:02d}-{简短英文描述}.md`

例如：`01-typing类型注解弃用说明.md`、`02-decorators详解.md`

序号 = 当前目录中最大序号 + 1。如果没有文件，从 `01` 开始。

### 4. 内容格式

每个笔记使用统一格式：

```markdown
# 标题

## 一句话总结

## 要点

- 点1
- 点2

## 代码示例（如果有）

```

如果是追加到已有文件，加二级分隔：

```markdown
---

### 追加于 2026-05-09

补充内容...
```

### 5. 注意事项

- **不要覆盖已有内容**，永远增量追加
- 不写废话，保持简洁
- 代码示例优先用 Python
- 如果涉及 Java 对比，保留对比说明
